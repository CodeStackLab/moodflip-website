🚀 How to Auto-Deploy Live to Vercel & Supabase

Follow these 3 simple steps to make your site live with continuous deployment on every git push:

  1. Push code to GitHub:
    git init
    git add .
    git commit -m "Deploy MoodFlip App"
    git branch -M main
    git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
    git push -u origin main
  2. Import to Vercel: Go to vercel.com/new, import your GitHub repository.
  3. Add Environment Variables in Vercel: Under Project Settings > Environment Variables, add:
    VITE_SUPABASE_URL = https://your-project.supabase.co
    VITE_SUPABASE_ANON_KEY = your-anon-key
